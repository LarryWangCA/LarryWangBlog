## BST Find Min, Prev, Next, Reverse （非dfs中序遍历后保存为数组的解法）
假设BST节点定义如下：  
```
struct Node {
    int val;
    Node* left;
    Node* right;
    Node* parent;
};
```
注意，root节点的parent为nullptr.     

1. findMin (找到 BST 的最小节点)
如果输入是任意节点，我们需要首先爬到根节点。
```
        // 1) climb to root
        Node* root = node;
        while (root->parent) root = root->parent;
```
思路：从根节点开始，一直向左子树走到底。这是一个简单的迭代过程，不需递归或栈。  
时间：O(H)，空间：O(1)。
```
Node* findMin(Node* root) {
    if (!root) return nullptr;
    Node* curr = root;
    while (curr->left) {
        curr = curr->left;
    }
    return curr;
}
```

2. findPrev (找到给定节点的前驱，即 inorder predecessor)  
思路：利用 parent 指针，非递归实现。  
如果节点有左子树：从左子树开始，向右走到底（左子树的最右节点）。  
如果没有左子树：从当前节点向上遍历 parent，直到找到一个祖先节点是其 parent 的右孩子；那个祖先的 parent 就是前驱。  
边界：如果节点是最小节点，前驱为 nullptr。  
时间：O(H)，空间：O(1)（无栈）  
```
Node* findPrev(Node* node) {
    if (!node) return nullptr;
    
    // 情况1: 有左子树，前驱是左子树的最右节点
    if (node->left) {
        Node* prev = node->left;
        while (prev->right) {
            prev = prev->right;
        }
        return prev;
    }
    
    // 情况2: 无左子树，向上找第一个是右孩子的祖先
    Node* curr = node;
    Node* par = curr->parent;
    while (par && curr == par->left) {  // 只要是左孩子，继续向上
        curr = par;
        par = par->parent;
    }
    return par;  // par 是前驱（或 nullptr 如果是最小节点）
}
```

3. findNext同理(Leetcode 510)  
```
class Solution {
public:
    Node* inorderSuccessor(Node* node) {
        // 情况1: 有右子树，后继是右子树的最左节点
        if (node->right) {
            node = node->right;
            while (node->left) {
                node = node->left;
            }
            return node;
        }

        // 情况2: 无右子树，向上找直到是左孩子
        Node* cur = node;
        Node* par = node->parent;
        while (par && cur == par->right) {  // 只要是右孩子，继续向上
            cur = par;
            par = par->parent;
        }
        return par;  // par 是后继（或 nullptr）
    }
};
```


4. reverse (逆序遍历 BST，即从最大到最小输出所有节点值)  
假设 "reverse" 意味着使用 findPrev 实现逆中序遍历（descending order）。因为有 parent，我们可以用迭代方式从最大节点开始，反复调用 findPrev，直到 nullptr。  
思路：  
先找到最大节点（从根向右走到底，类似 findMin 的镜像）。  
然后从最大节点开始，反复找前驱（findPrev），输出值，直到前驱为 nullptr。  
这避免了递归 DFS 或保存全列表到 vector（只需在遍历时处理，如打印或收集到输出流）。  
时间：O(N)，空间：O(1)（不存列表，只迭代处理）。
```
void reverse(Node* root) {
    if (!root) return;
    
    // 先找到最大节点（向右走到底）
    Node* curr = root;
    while (curr->right) {
        curr = curr->right;
    }
    
    // 从最大开始，反复找前驱并处理（这里用 cout 示例，你可改成收集到 string 或其他）
    while (curr) {
        std::cout << curr->val << " ";  // 处理节点值
        curr = findPrev(curr);
    }
    std::cout << std::endl;
}
```
